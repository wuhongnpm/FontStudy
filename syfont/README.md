# syfont

一个基于 Vue 3、Vue Router、Vuex 和 Element Plus 构建的字体学习前端项目。

## 技术栈

- Vue 3
- Vue Router 4
- Vuex 4
- Element Plus

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```
