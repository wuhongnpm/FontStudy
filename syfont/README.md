# syfont

一个基于 Vue 3、Vue Router、Vuex 和 Element Plus 构建的字体学习前端项目。

## 技术栈

- Vue 3
- Vue Router 4
- Vuex 4
- Element Plus

## 本地运行

建议使用当前 Node.js 的长期支持版本（LTS）。进入 `syfont` 目录后，安装依赖并启动开发服务器：

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```
